# 논문 트랙 실험 기록

u01(사전 맥락 적재)을 논문으로 이어 가기 위한 실험(E1~)의 기록이다. 실행 규칙은 `CLAUDE.md`의 "논문 트랙 실행 규칙"을 따른다.

## 실험마다 남기는 것 (`experiments/<ID>/`)

| 파일 | 언제 | 내용 |
|---|---|---|
| `preregistration.md` | 실행 전 | 질문과 가설, 조건(정확한 문구), 태스크, 지표, 분석 방법, 판정 규칙, 표본 크기 근거, 제외·중단 규칙. 커밋해서 시점을 남긴다 |
| `plan.json` | 실행 전 | 드라이버(`scripts/drive.py`)가 읽는 실행 계획. 환경 변수, 배치, Q4 채점, 분석 명령 |
| `log.md` | 진행 중 | 사람이 읽는 실험 일지. 준비, 시험 실행, 본 실행 시작과 끝, 한도 대기, 오류와 재실행, 계획에서 벗어난 점 |
| `run_log.txt` | 진행 중 | 드라이버가 자동으로 남기는 기록. 한도 사용률, 배치 명령, 실행별 결과 줄 |
| `results.md` | 분석 후 | 사전 등록한 비교와 판정, 생성기별 결과, 메커니즘, 품질, 해석과 한계 |

- 데이터: `results/<id>/runs.jsonl`(실행별 기록), `results/<id>/q4.jsonl`(Q4 채점), `results/raw/<id>/`(CLI 결과 원본), `results/<id>/analysis.*`(분석 출력)
- 사전 등록 밖의 탐색 분석은 코드를 `experiments/<ID>/explore.py`에, 출력을 `results/<id>/explore.md`에 남긴다.
- 실행 폴더(작업 사본, 실행 기록): `~/td-data/runs/<id>/` (저장소 밖, 재부팅에도 남는다)
- 보고서(HTML)는 요청이 있을 때만 만든다.
