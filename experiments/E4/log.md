# E4 실험 일지 (준비 중)

시각은 KST다. 시각은 `date` 출력, 파일 시각, 대화 기록의 시각으로 확인한 값만 쓴다.

## 목적

- 논문 주장 "출력 토큰 절감 + 정확도 유지"의 정확도 쪽을 믿을 수 있게 만든다.
- 지금까지 문제는 정확도가 천장(거의 모두 만점)이라, "떨어지지 않았다"는 말을 뒷받침할 검정력이 없었다.
- E4에서는 정확도에 차이가 생길 수 있는 문제를 쓰고, 정확도를 떨어뜨리는 양성 대조군으로 측정이 하락을 실제로 잡는지 먼저 보인다.

## 사용자 지시 (2026-10-12)

- 정확도에서 유의미한 차이를 보여야 한다(논문의 신빙성).
- 주간 사용량은 고려하지 않고 5시간 사용량만 본다. 그래서 `scripts/drive.py`와 `scripts/run.py`의 주간 90% 중단을 껐다(`TD_USAGE_LIMIT_7D` 기본값 1.01). `CLAUDE.md`에도 적었다.
- 실험을 모두 끝낸 뒤 논문을 쓴다.
- 20:58 "일단 여기까지 하고 진행상황 저장해놔. 나중에 할게"에 따라 준비 단계에서 멈추고 기록했다.

  - 결론: **명세가 분명하면 effort를 낮춰도 Opus는 틀리지 않는다.** 정확도 차이는 명세를 해석해야 하는 곳에서 생긴다(E2 탐색 결과와 같은 방향).
- **19:35~19:38 "검증해야 맞힐 수 있는 문제"(L7) 설계와 생성기 작성**
  - **배송비 L7** (`gen/tariff.py`): 산문 명세에 두 가지로 읽히는 곳을 넣고, `examples.json`의 예시만이 의도한 해석을 정해 준다.

    | 모호성 | 의도한 해석 | 다른 해석 |
    |---|---|---|
    | A 섬 무료배송 | 박스마다 내륙 최저 기본 요금을 깎는다 | 주문당 한 번 |
    | B 할인 순서 | 회원 할인 먼저, 쿠폰 나중 | 쿠폰 먼저 |
    | C 무게 요금 | 구간별로 나눠 센다 | 첫 구간 요금이 그 위 무게에도 겹쳐 붙는다 |
    | D 최소 요금 | 합계 0원은 0원 그대로 | 0원도 최소 요금으로 올린다 |
    | P (보정 중 발견) | B와 같음 | 두 할인액을 모두 할인 전 금액으로 계산해 함께 뺀다 |

  - **매출 L7** (`gen/sales.py`): L5와 같은 DB(UTC 저장, 표기가 섞인 세그먼트, 같은 email의 중복 계정)에서 시간대·세그먼트 정리·계정 병합 규칙을 정의에서 뺐다. 대신 같은 정의로 계산한 2분기 참고 값 10개를 준다. 질문 d·h는 분기 안의 값으로 바꿔 참고 값이 3분기 답을 드러내지 않게 했다.
  - 자동 확인(`tariff.ambiguity_check7`, `sales.ambiguity_check7`): 모든 문제에서 각 모호성을 가르는 예시나 참고 값이 있고, 숨은 정답도 각 모호성에 반응한다.
  - 양성 대조 조건 `conditions/e4_noverify`: "결과를 실행해 확인하거나 예시·참고 값과 대조하지 않는다. 처음 만든 결과를 바로 제출한다."

## E4 설계 초안 (사전 등록 전)

- **문제** (`tasks_e4`, 아직 만들지 않음): 배송비 L7 seed 201~236(36개) + 매출 L7 seed 201~236(36개) = 72개, 각 1회
- **조건 10칸 = 720회**

  | 조건 | effort |
  |---|---|
  | 베이스라인 (`baseline`, `e2_base_med`, `e2_base_low`) | high, medium, low |
  | n09 (`n09_p2_h05`, `e2_n09_med`, `e2_n09_low`) | high, medium, low |
  | P1 위약 (`e2_p1_med`), P2 간결 (`e2_p2_med`) | medium |
  | 검증 금지 (`e4_noverify`, 양성 대조) | high |
  | 서두름 신호 (`e4_hurry`, **아직 만들지 않음**) | high |

  - `e4_hurry`의 문구 후보: 벤더 문서의 시간 신호 문장. "시간이 중요하다. 피할 수 있는 시간은 쓰지 않고, 올바른 결과는 빠를수록 좋다."
- **주 결과는 정확도다** (`scripts/analyze_e4.py` 초안):
  - 주 비교 6개(정확도 차이, 양측, Holm): M1 검증 금지 대 베이스라인 high(조작 확인), M2 서두름 신호, E_low effort low, N_high·N_medium·N_low(n09 대 같은 effort의 베이스라인)
  - 비열등성 δ = 0.05(단측 95% 하한)
  - 토큰은 부 결과다.
  - 탐색 분석: 배송비 오답을 각 모호성의 다른 해석으로 설명해 본다.
