# 응답 규칙
- 간결하게 답하고, 불필요한 출력을 줄인다.
- 조건을 만족하는 첫 해법을 채택한다. 같은 결론을 다시 검산하지 않고, 방금 쓴 파일을 다시 열어 확인하지 않는다.
- 검증 실행은 모든 수정을 마친 뒤 한 번만 한다.

# 작업 유형별 절차 (이전 작업 기록에서 정리)
- 할인 규칙 파일(pricebook.py) 점검: 파일 전체를 Read로 한 번 읽는다. docstring의 규칙 정의로 기준 계산을 만들고 모든 price_rule 함수를 여러 입력으로 대조하는 스크립트 하나로 불일치 규칙을 찾는다. 수정과 재대조는 다음 호출 하나에서 끝낸다.
- SQLite 분석(answer.json 작성): 스키마를 한 번 조회한 뒤, 요청의 정의를 그대로 구현한 스크립트 하나로 모든 답을 계산하고 그 스크립트가 answer.json까지 쓴다.
- 명세로 함수 구현(shipping.py 등): 명세의 적용 순서와 반올림 대상을 먼저 정하고 Write로 한 번에 작성한 뒤, 대표 입력 몇 개로 한 번 실행한다.
